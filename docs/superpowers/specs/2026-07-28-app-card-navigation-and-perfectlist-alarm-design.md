# 应用卡片导航与 PerfectList 闹钟文案设计

**日期：** 2026-07-28  
**状态：** 已确认，待规格审阅

## 目标

首页每张应用卡片应把访问者带到应用详情页，而不是只让图标和“查看应用”文字可点击。唯一的例外是显式的 App Store 按钮，它必须保留当前 Storefront 解析后的外部下载链接。

同时，PerfectList 的详情页应首先说明其系统级闹钟与日程规则能力。这是该应用最突出的场景，不能被笼统的任务或习惯描述淹没。

## 卡片交互

- 每张 `AppCard` 使用一个绝对定位的详情链接覆盖整个卡片表面，链接目标为当前语言下的应用详情页。
- 图标、产品名称、摘要、空白区域和“查看应用”视觉标签都由该链接覆盖，因此点击任一处均进入详情。
- 通过 `z-index` 仅将 `AppStoreCTA` 生成的实际 App Store 锚点提升到详情链接之上；点击按钮继续跳转到已解析的地区商店。
- CTA 的地区提示文字不设为独立链接；点击它仍会落到详情链接。这保证例外仅限实际的 App Store 按钮。
- 不引入运行时点击事件。详情链接与 App Store 链接均为原生锚点，键盘焦点顺序保持为详情页链接后接 App Store 链接。

## PerfectList 内容

PerfectList 的每个语言版本继续保留五项功能，但调整为以下顺序：

1. **系统级闹钟与排班规则**：iOS 18+ 可使用 AlarmKit；说明节假日、工作日、单休、大小周、自定义周循环及每日/每周/月/年规则。
2. **农历与生日提醒**：说明农历日期、生日和重复日期。
3. **任务与系统日历**：说明优先级、分类、时间，以及与系统日历同步。
4. **习惯与番茄钟**：说明长期重复习惯和专注计时。
5. **跨设备查看**：说明 iPhone、iPad、Mac、Apple Watch、小组件及按用户设置启用的 iCloud 同步。

文案不得承诺所有系统版本均能突破静音或专注模式；只以“在支持的系统版本与授权条件下”描述 AlarmKit 闹钟。各语言版本分别撰写，保持与对应 App Store 名称和站点语言一致。

## 验证

- 为首页端到端测试增加断言：点击卡片摘要进入详情，点击 App Store CTA 保持外部 URL。
- 数据测试验证 PerfectList 第一项功能的标题和说明包含系统级闹钟及核心排班规则的对应语言表述。
- 构建、类型检查和现有语言/Storefront 回归持续通过；使用桌面与手机截图确认 CTA 保持可点击且卡片内容不被覆盖层遮挡。
