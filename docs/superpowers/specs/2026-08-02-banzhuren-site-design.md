# 班主任小秘书中文网站接入设计

## 目标

将 `/Volumes/外置硬盘/Developer/班主任` 工程中的应用以“班主任小秘书”加入 FU apps 网站，并立即提供可公开访问的中文隐私政策、用户支持和服务条款。应用尚未上架 App Store，因此网站显示“上架中”，不生成或展示伪造的商店链接。

本次接入只面向简体中文站点。现有五个已发布应用继续保持五种语言；班主任小秘书只生成 `/zh-Hans` 下的页面和文档。

## 方案

### 目录模型

扩展应用和法律文档的数据模型，使一个应用可以声明支持的站点语言：

- 现有应用继续支持全部 `Locale`，行为不变。
- 新应用声明仅支持 `zh-Hans`，应用首页、详情页和法律页面的静态路径只为该语言生成。
- `AppRecord` 的 App Store ID 和 listing URL 对未上架应用可缺省。
- `planned` listing 可以没有 URL；有 URL 时保留现有“计划发布”兼容行为，没有 URL 时渲染为非链接的“上架中”状态。

首页按当前 locale 过滤应用，详情页和文档页的 `getStaticPaths` 只生成应用支持的语言，避免在其他语言路由中出现中文内容或空文档。内容校验也按每个应用的支持语言计算，不降低已有应用的五语言要求。

### 用户界面

新增应用卡片、详情页和截图区域沿用现有 Astro 组件与视觉样式：

- slug 使用 `banzhuren`。
- 中文展示名称使用“班主任小秘书”。
- 应用卡片的商店区域显示“上架中”，不产生新窗口、不跳转到 App Store 首页。
- 详情页保留功能、截图和“应用文档”入口；三个文档入口指向：
  - `/zh-Hans/apps/banzhuren/privacy`
  - `/zh-Hans/apps/banzhuren/support`
  - `/zh-Hans/apps/banzhuren/terms`
- 将来获得 App Store ID 后，只需补充 listing 数据即可恢复可点击的 App Store CTA，不改变页面 URL。

应用介绍和至少五条功能说明只描述当前工程中已经存在的能力：班级与学生资料、成绩与考试分析、课程与日程、待办与提醒、操行/请假/寄宿等工作记录、局域网电脑编辑、表格导入导出和意见建议记录。截图使用工程图标与可从当前应用运行状态取得的屏幕素材，不修改班主任工程。

### 法律文档

新增 `src/data/legal/banzhuren.ts` 并注册到法律文档索引。文档只提供 `zh-Hans` 内容，更新日期为实现当天，公开联系邮箱使用已批准地址 `fxcpxs@163.com`。

隐私政策明确说明：

- 用户主动录入或导入的班级、学生、家长联系方式、成绩、课程、考勤/请假、操行、待办、反馈和语音待办数据。
- 数据默认保存在设备本地 Core Data 和应用支持目录，开发者不以自有服务器接收这些班级资料。
- 语音待办会使用麦克风录音和系统语音识别；是否由设备本地处理取决于系统能力和授权，录音及转写结果用于用户请求的功能。
- 通知用于待办提醒；相册权限仅用于将用户主动生成的图片保存到系统相册。
- 用户主动启动局域网编辑时，同一局域网内的电脑可在配对码和会话令牌保护下编辑当前班级数据；服务只在应用前台运行。
- 节假日数据刷新会请求网络数据，但不将班级资料作为该请求内容上传。
- Apple StoreKit 和 Apple ID 负责一次性“终身解锁”购买、交易验证与恢复购买；开发者不接触 Apple ID 支付凭据。
- 用户可以在应用内删除记录或卸载应用删除本地数据；导出的 CSV/Excel 和用户保存的语音/图片副本由用户自行管理。

用户支持页说明支持邮箱、问题报告所需的版本/设备/系统/复现步骤，以及不要求密码、Apple ID 凭据或不必要个人资料的支持边界。服务条款说明个人/学校数据责任、用户对输入和导出内容的责任、局域网访问控制、第三方 Apple 服务和网络可用性、一次性购买、免责声明、条款更新和联系渠道。

### 来源记录

在 `docs/legal-source-map.md` 增加班主任小秘书一行，记录工程目录、当前没有独立政策源文件、网页文案基于工程配置和运行行为整理，并注明公开联系邮箱。原工程不新增或修改法律文档。

## 数据流与边界

```text
班主任工程事实
  -> AppRecord / banzhuren legal profile
  -> zh-Hans 静态路径
  -> 首页卡片、应用详情、privacy/support/terms 页面
```

构建期不访问班主任运行时数据，也不把学生资料复制到网站仓库。网站只发布产品介绍和政策文字。未上架应用没有 App Store URL，CTA 作为状态展示处理；若 listing 数据误配置为 live 但缺少 URL，内容校验必须失败。

## 错误处理

- 不支持的语言不会生成班主任小秘书页面；直接访问未生成的路径进入现有 404 页面。
- 未上架 listing 缺少 URL 时显示“上架中”，不会渲染空 href、`#` 或虚假商店地址。
- 应用图标、截图、中文功能文案或三类中文法律文档缺失时，内容校验失败。
- 现有应用的语言、listing、法律页面和 App Store CTA 行为不得因本次新增应用改变。

## 测试与验收

- 更新内容校验：现有应用仍要求五语言；班主任小秘书要求简体中文，应用总数更新为六个。
- 增加数据测试：班主任小秘书仅支持 `zh-Hans`，包含五条功能说明、三类法律文档、批准邮箱和无商店 URL 的上架中 listing。
- 增加页面/渲染测试：中文首页包含应用卡片，详情页和三个中文文档路由可生成；其他语言不生成该应用页面。
- 运行 `npm test`、`npm run validate`、`npm run build`；如本地环境可用，再运行 `npm run test:e2e` 检查首页、详情页、政策导航和上架中状态。
- 检查 git diff，确认只修改 WEB 仓库及从班主任工程复制到 WEB `public/assets` 的派生媒体，不修改班主任工程源文件。

## 非目标

- 不修改班主任 iOS 工程的功能、权限声明、购买逻辑或政策源代码。
- 不为班主任小秘书编写英文、繁体中文、日文或韩文页面。
- 不创建虚假的 App Store ID、商店名称或上线链接。
- 不把学生数据、反馈数据或其他运行时内容上传到网站。
