# 佳佳照片 Build 8 官网对齐规范

## 目标

让官网产品卡片、应用文案和隐私/支持/服务条款与当前已安装的 1.1.1（Build 8）一致：应用名称为「佳佳照片 / JiaJia Photo」，产品是通用人像照片编辑器，不生成或声称生成任何身份证、护照、签证、文凭、证书或其他官方文件。

## 当前事实基线

- Bundle ID：`com.pans.jiajia-photoid`；版本：`1.1.1 (8)`。
- 已验证的产品流程：拍摄或从照片选择人像、设备端人像处理/抠图、背景与亮度调整、自然美化、4:5/方形/3:4/4:3/自由裁剪、导出 PNG/JPEG、保存到照片或分享。
- 照片、临时人脸位置数据和图像处理均在设备端进行；应用可能请求公开版本和推荐内容，但请求不包含照片、面部数据或身份信息；不集成广告或行为分析服务。
- 地区、语言偏好和公开推荐缓存保留在设备本地；照片只有在用户主动保存时才写入系统照片库。
- 当前支持的 App Store Connect 本地化名称均使用 `佳佳照片`（中文）或 `JiaJia Photo`（英语/法语品牌名）。

## 对齐范围

- 官网 `src/data/apps.ts` 的名称、功能、市场列表和产品图引用。
- 官网 `src/data/legal/jiajia-id-photo.ts` 的五种站点语言隐私政策、支持页和服务条款。
- 与上述内容相关的 storefront 单元测试和法律文档完整性测试。
- 应用仓库的审计记录与截图生成工作流文档；本次不把 GitHub 主分支旧源代码冒充成 Build 8，也不在未批准时推送。

## 不在本次范围

- 不恢复或保留证件照规格、政府机构模板、护照/签证/驾驶证/考试报名用途或实体打印排版宣传。
- 不修改 App Store Connect 已上传的旧版本媒体；Build 8 媒体仍须用户预审后再上传。
- 不提供法律意见；政策文字只做产品事实一致性校对。

## 验证标准

- 官网源码中 `jiajia-id-photo` 的产品文案、名称和法律文档不再声称支持官方证件或打印排版。
- 五个站点语言均有完整的隐私、支持和服务条款；名称只出现 `佳佳照片` 或 `JiaJia Photo`，不出现 MapleLens ID、US PassSnap、证照准拍、證照好拍。
- `npm run validate`、`npm run check`、`npm test` 和 `npm run build` 均通过。
- 截图工作流明确记录设备、区域/语言、流程、文件命名、尺寸检查、混入语言检查和审批/上传闸门。
